# Changelog

## 2.0.0
- Converted to ES modules with explicit imports and one shared state object
- Round turntable decks, tempo-aware light show with dark flashes, volume up to 200% with a limiter
- One audio graph in audio.js; all panel markup now in index.html
- Pure music, key and BPM logic in js/lib with unit tests
- Page test that runs the whole app in jsdom, ESLint, and CI that runs all of it
- sw.js file list and cache name are generated by npm run build

## 1.1.0
- BPM detection, deck sync and EQ
- Themes, saved settings, keyboard shortcuts, help dialog and share button
- Accessibility labels and reduced-motion support
- Offline support, project check script and CI

## 1.0.0
- Hand-tracked synth with scale lock and a note ladder
- DJ mode, looper, sampler, 50 face characters, video filters and recording
- Split into modules with GitHub Pages deployment

## 0.1.0
- First prototype: hand-tracked theremin with recording
