# Changelog

## 2.3.0
- Party mode works for friends in different places: a free shared relay steps in when a direct link fails, with your own relay or provider link as the better option
- Laptops reconnect by themselves after a drop, the list shows each friend's delay and whether they are direct or via relay, and Check my connection explains what your network can do
- Optional small video sharing in a room (off by default)
- New bar under the stage with the instrument, key, volume, room and full screen; WhatsApp invite
- Layout fix: the page keeps a fixed height, so the stage no longer drifts down on long tabs and the side panel scrolls on its own

## 2.2.0
- Party mode works across networks: add free TURN relay details under Connection help, or in js/config.js
- The laptop list shows whether each laptop is linked directly or through the relay
- Joining failures now suggest a relay when none is set

## 2.1.0
- Party mode: connect laptops with a room code to share songs, lights and effects, and hand control to whoever presses play
- Light show beats are sent by the DJ laptop so every screen shows the same show
- Sound effect keys now go through the pads, so they are shared too

## 2.0.0
- Converted to ES modules with explicit imports and one shared state object
- Round turntable decks, tempo-aware light show with dark flashes, volume up to 200% with a limiter
- One audio graph in audio.js; all panel markup now in index.html
- Pure music, key and BPM logic in js/lib with unit tests
- Page test that runs the whole app in jsdom, ESLint, and CI that runs all of it
- sw.js file list and cache name are generated by npm run build

## 1.1.0
- BPM detection, deck sync and EQ
- Themes, saved settings, keyboard shortcuts, help dialog and share button
- Accessibility labels and reduced-motion support
- Offline support, project check script and CI

## 1.0.0
- Hand-tracked synth with scale lock and a note ladder
- DJ mode, looper, sampler, 50 face characters, video filters and recording
- Split into modules with GitHub Pages deployment

## 0.1.0
- First prototype: hand-tracked theremin with recording
