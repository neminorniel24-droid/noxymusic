# Contributing

## Setup
Run `npm install`, then `npm start` and open http://localhost:8000.

## Guidelines
- Plain HTML, CSS and ES modules, no bundler. Dev tools only (ESLint, jsdom)
- Run `npm run verify` before you push. It lints, checks and runs all tests
- After adding or removing a file under css, js or assets, run `npm run build`
- One feature per pull request, with a clear description
- Test in Chrome and Edge, with and without a camera

## Reporting bugs
Open an issue with your browser, steps to reproduce and any console errors.
